> 一款专为 Windows 用户设计的批量图片水印工具，自定义文字水印、批量处理、一键导出。

## ✨ 功能介绍

- 📷 **批量添加水印**：支持 JPG / JPEG / PNG / BMP / WEBP 格式，一次处理多张图片
- 🔤 **自定义水印文字**：自由设置水印内容（如 `© 2026 My Photo`）
- 📍 **5 种位置**：左上角 / 右上角 / 左下角 / 右下角 / 居中
- 🌫️ **透明度可调**：0.1 ~ 1.0 滑动调节，柔和或醒目随心
- 🔠 **字体大小可调**：12 ~ 72 像素，适配不同图片
- 💾 **灵活输出格式**：保持原格式 / JPG / PNG / WEBP
- ⚡ **多线程处理**：实时进度条，处理状态一目了然
- 🖥️ **单文件绿色版**：下载即用，无需安装
